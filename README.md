# 📚 Libft

Ma première librairie en C, faite à 42 Paris : je recode des fonctions de la libc pour comprendre comment elles marchent vraiment, et je m'en sers ensuite dans tous mes projets.

> [!NOTE]
> 43 fonctions en 3 parties : **libc** (`strlen`, `memcpy`, `atoi`...), **additionnelles** (`split`, `itoa`, `substr`...) et **listes chaînées** (`ft_lstnew`, `ft_lstmap`...).

## ⚙️ Utilisation

```bash
make
```

Génère `libft.a` à la racine. Autres règles : `make clean`, `make fclean`, `make re`.

## 📎 Ressources

- Pages de manuel (`man strlen`, `man memcpy`, `man ar`), documentation de `make`.
- Wikipédia, Stack Overflow, GeeksforGeeks.
